# Code of Conduct

We want this project to be welcoming to people using different TVs, platforms, languages, and levels of experience.

## Expected behavior

- Be respectful and constructive in issues, reviews, and discussions.
- Focus feedback on the work, with enough detail to help someone act on it.
- Respect differing experiences, identities, and viewpoints.
- Help keep device logs, IP addresses, and other personal information out of public reports.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks, doxxing, and repeated disruptive behavior are not accepted.

## Reporting and enforcement

Report conduct concerns privately to the maintainer at **echo.ridwanramadhan@gmail.com**. Include links or context if safe to share. Reports will be handled as confidentially as practical. The maintainer may edit or remove content, warn participants, or restrict participation, depending on severity. If the concern involves the maintainer, use GitHub's platform reporting tools.

This policy applies to repository issues, pull requests, discussions, and other project spaces.
